# PINNeAPPle-Climate 🍍

### The open reference for Physics AI in climate & earth systems — weather forecasting, climate modeling & ocean-atmosphere simulation

This repository is an open, continuously-updated **reference and knowledge hub** for **Physics AI** — physics-informed and scientific machine learning — applied to this industry. It maps the current landscape (research, model architectures, commercial products, numerical solvers, datasets, geometries, standards) and lays out a roadmap to become the most complete public resource in this space.

Part of the [PINNeAPPle Labs](https://github.com/PINNeAPPle-Labs) family — built on the same open-source Physics AI foundation as [PINNeAPPle](https://github.com/PINNeAPPle-Labs/PINNeAPPle).

## 📖 The Reference Document

The full landscape map lives in **[docs/REFERENCE.md](docs/REFERENCE.md)**, covering:

1. Academic research landscape (labs, landmark papers, venues)
2. Model architectures (PINNs, neural operators, GNNs, foundation models, hybrid/differentiable solvers)
3. Commercial products & startups
4. Numerical methods & solvers used as baselines or hybridized with ML
5. Geometry, CAD & mesh resources
6. Datasets & data generators
7. Industry standards, validation & certification context
8. Open challenges & gaps
9. Roadmap to become the reference hub for this field
10. Sources

This document is a **living artifact** — corrections, additions, and new sources are welcome via pull request.

---

## 🎯 Why this repo exists

Physics AI is fragmenting fast across every physical industry: new architectures, new startups, new benchmarks appear every month, scattered across arXiv, vendor blogs, and conference proceedings. There is no single, maintained, open map of the field for this industry. This repo aims to be that map — the first stop for a researcher, engineer, or founder asking *"what already exists in Physics AI for this industry, and where are the gaps?"*
