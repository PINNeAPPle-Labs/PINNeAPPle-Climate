# Contributing to PINNeAPPle-Climate

This repo is primarily a **curated knowledge base**, not a software package — so most contributions are edits to [docs/REFERENCE.md](docs/REFERENCE.md).

## How to contribute

1. Open an issue or PR with the specific addition/correction.
2. Cite a real, checkable source (paper, repo, vendor page) for any new claim.
3. Keep entries factual and neutral — no marketing language for commercial products.
4. If you're adding a dataset, tool, or solver, include: what it is, who maintains it, and a link.
5. Flag outdated or superseded information you notice (this field moves fast — funding rounds, acquisitions, and renamed products happen often).

## Style

- English, Markdown, one fact per bullet where possible.
- Prefer primary sources (papers, official docs) over secondary blog posts.
- Uncertain or unverifiable claims should be marked as such rather than stated as fact.

## Scope boundaries

Contributions should stay within physics-informed / scientific ML applied to this industry — general ML/AI content without a physics-simulation angle belongs elsewhere.
